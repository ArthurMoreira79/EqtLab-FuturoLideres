## Deploy na Vercel

1. Importe este repositório na Vercel.
2. Em **Root Directory**, escolha `site`.
3. Framework: Next.js (detectado automaticamente). Não é preciso variável de ambiente: sem `IA_PROVEDOR`, a avaliação usa o modo simulado.
4. Deploy.
